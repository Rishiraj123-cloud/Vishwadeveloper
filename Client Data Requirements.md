# Real Estate Website Data Requirements Checklist

To make the Vishwa Developers platform fully ready for the public, you need to collect the actual business data from the website owner. Use this checklist as a questionnaire to hand to the client.

## 1. General Business Information
These details will be used in the footer, the "Contact Us" page, and system emails.
- [ ] **Official Company Name:** (e.g., Vishwa Developers LLC)
- [ ] **Company Logo:** (High-resolution, preferably in PNG format with a transparent background. Need one for the dark theme and one for the light theme, or a versatile version).
- [ ] **Primary Phone Number:** (The main sales/support line)
- [ ] **WhatsApp Number:** (If they use a different number for WhatsApp inquiries)
- [ ] **Primary Contact Email:** (e.g., sales@vishwadevelopers.com)
- [ ] **Physical Office Address:** (Full address including pin code for the map on the Contact page)
- [ ] **Working Hours:** (e.g., Mon-Sat: 9:00 AM - 6:00 PM)

## 2. "About Us" Content
This will populate the `about.html` page to build trust with buyers.
- [ ] **Company Mission/Vision Statement:** (A short paragraph describing their goal)
- [ ] **Company History:** (When they started, how many properties they've sold, any awards won)
- [ ] **Founder's Message:** (Optional: A quote or short message from the CEO/Founder)

## 3. Team / Agents Information
This will populate the `agents.html` page. For each core team member or top agent, please provide:
- [ ] **Full Name**
- [ ] **Job Title / Designation** (e.g., Senior Sales Executive)
- [ ] **Professional Headshot Photo**
- [ ] **Contact Email & Phone Number**
- [ ] **Brief Bio:** (1-2 sentences about their expertise)

## 4. Initial Property Inventory (Seed Data)
To ensure the website doesn't look empty on launch day, they need to provide a "starting batch" of properties. For at least 5-10 properties, ask for:
- [ ] **Title:** (e.g., Luxury Sea-View Villa)
- [ ] **Location:** (Exact area and city, e.g., Whitefield, Bangalore)
- [ ] **Property Type:** (Villa, Apartment, or Plot)
- [ ] **Purpose:** (For Sale or For Rent)
- [ ] **Price:** (Exact figure, e.g., ₹1.5 Cr or ₹35,000/month)
- [ ] **Dimensions:** (Total square footage / Area)
- [ ] **Configuration:** (Number of Bedrooms and Bathrooms)
- [ ] **Description:** (A detailed marketing paragraph about the property features)
- [ ] **High-Resolution Photos:** (At least 3-5 high-quality, landscape-oriented photos per property. The first photo will be the cover image).

## 5. Social Media Links
To link the icons in the footer to their actual social media presence.
- [ ] **Facebook Page URL**
- [ ] **Instagram Handle / URL**
- [ ] **LinkedIn Company Page URL**
- [ ] **Twitter / X Profile URL**

## 6. Technical / Admin Setup
Information needed for hosting and backend setup.
- [ ] **Domain Name:** (Do they already own `vishwadevelopers.com`? If yes, you will need the login for their domain registrar like GoDaddy to point it to Render).
- [ ] **Admin Email Account:** (The email address they want to use to log into the Owner Dashboard / CRM).
- [ ] **Business Email Provider:** (If they want emails sent from `info@vishwadevelopers.com` instead of a generic email, they need to provide access to their professional email hosting to verify the domain in Resend).

## 7. Legal (Optional but Recommended)
- [ ] **Privacy Policy:** (How they handle lead data)
- [ ] **Terms and Conditions**
